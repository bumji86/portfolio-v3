## 3. Data Visualization

- **Title**: Data Visualization
- **Cover image**: (현재 카드 이미지 사용 — `img-cases/3.jpg`) → 바꿀 경우: [ ]
- **Summary**: [Turned promotion data scattered across spreadsheets into a single self-built dashboard.]
- **Tags**: Data, Insights, [Dashboard]
- **Body**:

  [Promotion performance data lived in dozens of individual Excel files, each owned by a different person. Reviewing how a campaign actually performed meant manually stitching files together every time — slow, error-prone, and impossible to compare at a glance. I designed and built a dashboard to fix the root cause rather than the symptom: a repeatable flow of gather → clean and standardize → visualize, so the same numbers landed in one shared view. The result was that campaign results became readable in one place instead of a folder of spreadsheets, and the team could compare across promotions without rebuilding the data each time. The lesson: most "data problems" are really format problems — standardize the input and the insight follows.]
